# Physical Promotional Collateral

Load this file for bags, fans, boxes, packaging, handouts, signs, and other physical campaign
surfaces.

## Distinguish artifact roles

- `reference`: informs direction only.
- `approved-mockup`: freezes appearance and relationships; it is not automatically production art.
- `production-master`: measurable artwork prepared for fabrication.
- `authoritative-asset`: official logo, copy, die line, color standard, or licensed font.

Never silently downgrade an approved mockup to a style reference.

## Intake requirements

Record:

- finished size and artwork size;
- bleed, trim, safe area, and die-line ownership;
- material, print method, ink or color limitations, and minimum line/text size when known;
- required copy, punctuation, logo version, and authoritative source;
- front/back/side relationships;
- requested editable and delivery formats.

Mark unknown production values as unresolved. Do not invent a printer specification.

## Production gates

Before execution:

- identify the approved mockup and hash or stable reference;
- list exact allowed changes and protected relationships;
- verify authoritative assets or label placeholders;
- separate visual approval from production readiness;
- confirm that claimed native formats can actually be produced.

After execution:

- verify physical dimensions, pixels and DPI where relevant;
- verify exact copy and punctuation;
- inspect trim and safe-area risk;
- inspect logo geometry and source;
- render PDFs and inspect the rendered result;
- verify file signatures instead of trusting extensions;
- label obsolete versions so they cannot be sent to production.

Use deterministic layout and vector assets for text, logos, die lines, and accepted composition.
Use image generation only for artwork that genuinely requires synthesis.
