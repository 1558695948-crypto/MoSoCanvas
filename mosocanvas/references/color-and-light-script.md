# Color and light script

Use this for every authored series and for single images where color carries narrative meaning.

## Specify roles, not adjectives

Define:

- dominant field color;
- structural neutral;
- attention accent;
- skin/material bias where relevant;
- black point and highlight ceiling;
- saturation owner;
- warm/cool relationship;
- light source, direction, size, falloff, and motivated practicals.

Use measured color values only when sampled or when the delivery pipeline requires them. Otherwise
record ranges and relations.

## Build a series script

For each frame record:

- value key: low, middle, or high;
- dominant hue family;
- accent hue and approximate area share;
- contrast locus;
- source motivation;
- continuity invariant;
- intentional transition from the previous frame.

Design the contact sheet as a sequence of tonal events. Adjacent frames should either form a
controlled bridge or a deliberate rupture.

## Preserve hierarchy

Check in this order:

1. grayscale value hierarchy;
2. local contrast at the first-read target;
3. saturation hierarchy;
4. hue relationship;
5. fine color grading.

If grayscale fails, changing complementary colors is not a structural repair.

## Avoid pseudo-scientific claims

Do not claim a hue universally causes trust, fear, luxury, or intelligence. State the contextual
mechanism: contrast with the surrounding field, cultural association in the target context,
material plausibility, or recurrence established inside the series.

## Detect generator color defaults

Flag:

- teal-orange applied without source motivation;
- all highlights sharing one synthetic hue;
- uniformly lifted blacks and global bloom;
- accents scattered across the frame instead of owning attention;
- palette changes between frames without narrative consequence;
- reflective materials producing incompatible light environments.

Correct lighting logic and value ownership before adding a stronger grade.
