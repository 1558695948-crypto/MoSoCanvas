# MoSoCanvas v1.6.0

This release changes repeated image repair from a chain of regenerated full frames into a persistent,
non-destructive edit document.

- preserves an immutable clean anchor and a content-addressed asset history;
- prepares model inputs from the clean anchor plus explicit accepted dependencies;
- limits commits to a real write mask and exact deterministic compositing;
- binds each operation to its plan, raw candidate, staged review artifact, preservation report, and receipt;
- rejects stale plans, changed evidence, unreviewed candidates, and operation graphs that cannot replay;
- adds `edit-state`, `prepare-edit`, `stage-edit`, and `commit-edit` command-line entry points;
- extends strict preflight checks, schemas, examples, documentation, evaluations, and regression tests.

The release archive contains the complete `mosocanvas/` skill. The manifest records every packaged
file with its SHA-256 digest for integrity verification.
