# MoSoCanvas v1.7.0

New designs can express a direct feeling or a flat arrangement without inventing a hidden story
or a depth stack. Visual Spec 0.6 records how important concepts enter the image: explicit,
relational, context-only or intentionally omitted, including omission costs and visibility duties.

- Makes narrative devices optional for new Specs and supports flat/shallow/deep/mixed Shot Plan 0.2.
- Keeps the full design record outside native image tool arguments; compiles selected visual
  instructions and records their destinations without inferring permission to omit requirements.
- Preserves hard include/avoid/preserve rules, exact text, reference roles and repair obligations.
- Adds evidence-based selection findings to the existing review path; checks meaning retained,
  attention competition, detail/depth function and both benefits and losses of simplification.
- Retains legacy Spec 0.4/0.5 behavior and existing editing, review-choice and acceptance boundaries.
- Adds deterministic routing/preservation regressions and behavioral cases across sparse/dense,
  flat/deep, narrative/direct and mandatory multi-object briefs.

Passing implementation checks establishes contract behavior only. Actual image quality and viewer
understanding require the separate controlled study. This release passes 83 automated tests and
the strict schema, example, command-line and documentation checks. Two legacy compilation cases
produce the same image-tool arguments as v1.6.0.

The release archive contains the complete `mosocanvas/` skill. The accompanying manifest records
every packaged file and its SHA-256 digest.
